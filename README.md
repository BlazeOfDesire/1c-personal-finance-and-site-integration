# 1С: Личные финансы и интеграция сайта с 1С

Учебный проект на платформе **1С:Предприятие 8.3**.  
В одной конфигурации реализованы два самостоятельных блока:

1. Учёт личных доходов и расходов.
2. Интеграция HTML-формы сайта с 1С для приёма заявок.

## Проект 1. Личные финансы

Конфигурация позволяет учитывать доходы и расходы по счетам, формировать движения в регистре накопления и смотреть остатки.

### Реализовано

- Подсистема "Финансы".
- Справочники: "Счета", "Статьи доходов", "Статьи расходов".
- Документы "Доход", "Расход".
- Регистр накопления "Денежные средства" вида "Остатки".
- Проведение документов с формированием движений "Приход" и "Расход".
- Отчёт "Доходы и расходы за период",  "Движения денежных средств" на СКД.

### Логика учёта

Доход формирует движение "Приход", расход — "Расход".  
Остаток по счёту рассчитывается как разница между приходами и расходами.

## Проект 2. Интеграция сайта с 1С

HTML-форма на сайте отправляет заявку в PHP-обработчик. Заявка сохраняется на хостинге, после чего 1С забирает её по защищённому ключу и создаёт документ «Заявка с сайта».

### Архитектура

```text
HTML-форма → send.php → send-zayavki.php → JSON на хостинге
                                                ↑
1С: обработка "Загрузить заявки с сайта" → создание документа
```

### Реализовано

- HTML-форма с полями ФИО, email, телефона, города, организации, услуги и другими данными.
- PHP-обработчик `send.php` для сохранения заявки.
- API `send-zayavki.php` для добавления, выдачи и отметки заявок.
- Защита доступа секретным ключом.
- Обработка 1С "Загрузить заявки с сайта".
- Создание документа "Заявка с сайта" из JSON.
- Защита от повторного создания одной и той же заявки.
- Управление статусами: "Новая", "В работе", "Обработана", "Отклонена".
